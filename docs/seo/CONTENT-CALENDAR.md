## Every month

- Read GSC: queries with impressions at position 8–20 → improve that page.
- Check AI answers for "AI-konsult Göteborg" (ChatGPT, Perplexity, Google AI Mode). Log result.
- Ask one client for a Google review.
- Add new pages to `llms.txt` (it reads routes, so new page kinds need a line there).

## Guide template (each guide)

1. Title = the question.
2. First paragraph (40–60 words) answers it fully.
3. Steps or a table.
4. One first-hand example with a number.
5. "Vad det kostar" section when it fits.
6. Link to one service page and the booking page.
7. Byline, date, "uppdaterad" date.
